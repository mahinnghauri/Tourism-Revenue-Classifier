# 
Tourism Revenue Classifier

## Overview

The **Tourism Revenue Classifier** is a web-based application that classifies tourism locations into **High Revenue** or **Low Revenue** categories based on user-provided inputs. The project is developed to demonstrate practical skills in **application deployment, API integration, and interactive user interfaces**, rather than focusing on advanced machine learning complexity.

## Technology Stack

* **Python** – Core programming language
* **Gradio** – Interactive web-based user interface
* **FastAPI** – High-performance API framework
* **Flask** – Lightweight backend framework

## Key Features

* Intuitive and minimal user interface
* Instant prediction output based on user inputs
* Modular structure for easy maintenance and extension
* Suitable for academic, learning, and demonstration purposes

## Installation and Execution

1. Install the required dependencies:

   ```bash
   pip install gradio fastapi flask
   ```
2. Run the application:

   ```bash
   python app.py
   ```
3. Access the application through the local URL generated in the terminal.

## Project Scope

This project emphasizes **deployment workflow, UI interaction, and backend integration**. The prediction logic is intentionally kept simple and can be replaced with a fully trained machine learning model in future enhancements.
